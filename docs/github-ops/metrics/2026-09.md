### 口径说明（跨月不变）

- Traffic 四项指标固定为：14 天访问次数、独立访客、14 天克隆次数、独立克隆者；
- 「访问高但克隆为 0」= README 没能把人送到快速开始；
- 「克隆有但 Issue/PR 为 0」= 只被当资料下载，没进社区，属于第 13 保的漏斗问题；
- 长期为零的指标：**砍掉对应工作**，而不是继续维护。
