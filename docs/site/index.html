Quick Start

环境要求：JDK 21 LTS + Maven 3.9+（用仓库自带 ./mvnw 即可）+ Docker（可选）。 不需要任何密钥就能跑通编译与单测。 

git clone git@github.com:lifuchun522/springaialibabapractice.git
cd springaialibabapractice
./mvnw -B -ntp clean verify        # 编译 + 单测 + 架构图门禁 + 索引死链门禁

想看完整效果：按仓库 README 第七节一键启动（docker compose 一条命令起全套）。 遇到「跑不起来」请先到 Discussions 问答 提问（工作日 48 小时内首次响应）。

FAQ

问题答案
版本和章节是一回事吗？ 不是。ch* 是教程章节标签，v* 是软件版本。要看版本改动去 Releases，要按课程学去 README。
该从哪一掌开始读？ 按角色选路线，不要从头读到尾。见 Discussions #60 的起点对照。
仓库有治理/运维相关的文档吗？ 有，十三保仓库运营治理在 docs/github-ops/。
发现安全漏洞怎么办？ 不要在公开 Issue 里贴细节，走 私密漏洞报告。 见 SECURITY.md。
本地跑需要哪些密钥？ 编译与单测不需要任何密钥。要调真实模型时用环境变量注入，见 .env.example。

贡献入口

  • 开始之前读 CONTRIBUTING.md： 三条贡献路径 + 提交前三步。
  • 合适第一次贡献的任务带 good first issue 标签， 每个都写了「要做什么 / 验收标准 / 改动范围」。
  • 报告缺陷用 Issue 表单； 「验收标准」是必填项——没有它的问题无法被判定完成。
  • 本地流程速查（Git / gh / Desktop 三入口 + 冲突只解不覆盖）： 02-local-clients.md。
合并策略为 squash，main 禁强推、禁删除、必须过 CI； 回滚用 gh pr revert，不重写历史。 仓库运营治理的十三个主题索引见 docs/github-ops/README.md。
