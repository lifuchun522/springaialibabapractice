## 三、核验发现与踩坑

1. **依赖收敛门禁第一次真的拦住构建**：Hibernate 走 `antlr4-runtime 4.13.0`，Spring AI 的 ST 模板走 `4.13.1`，
   `dependencyConvergence` 直接失败。处置是统一到 4.13.1（父 POM 里显式管版本），不是关掉门禁。
2. **Windows PowerShell 传中文 JSON 请求体会被转成 GBK**，服务端解析失败返回 400。
   正确做法是把请求体写成 UTF-8 文件后用 `curl -d @file`；这条对后续所有真实调用验证都适用。
3. **`"$projectId:session-1"` 在 PowerShell 里不是拼接**：`$var:name` 会被当成带命名空间的变量引用，
   必须写成 `'{"user":"' + $projectId + ':session-1"...}'`。第一次调用 Bridge 时因此拿到 `-1`。
