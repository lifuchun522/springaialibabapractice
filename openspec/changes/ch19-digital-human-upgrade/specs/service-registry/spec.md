# Spec Delta

## Purpose

让「谁能被找到」成为一件可查询、可校验、可降级的事：数字人主服务与知识 Agent 的实例位置、
以及各 MCP 服务对外提供的能力清单，统一登记到一处注册中心，供调用方在运行期发现，
而不是靠配置文件写死地址。

## ADDED Requirements

### Requirement: 实例注册与注销

服务实例 SHALL 能在启动时把自身可被外部访问的地址登记到注册中心，并在正常关闭时注销。
登记的地址 MUST 是其他实例真正能连上的地址，MUST NOT 是回环地址（除非同机部署被显式声明）。

#### Scenario: 启动时登记可访问地址

- **WHEN** 一个实例以「已配置注册中心地址」的方式启动
- **THEN** 注册中心上出现该实例的一条记录
- **AND** 记录中的地址是外部可路由的地址与端口，而不是 `127.0.0.1`

#### Scenario: 同机部署显式声明回环地址

- **WHEN** 部署方显式把对外地址配置为回环地址
- **THEN** 系统按配置登记该地址，并在启动日志中明确提示「该地址仅同机可达」

#### Scenario: 正常关闭时注销

- **WHEN** 实例收到正常关闭信号
- **THEN** 该实例的注册记录被移除，调用方不再能发现它

### Requirement: 注册结果可校验

登记动作 SHALL 在返回前校验「注册记录能被查询回来」，MUST NOT 只以「调用未抛异常」作为注册成功的依据。

#### Scenario: 注册成功

- **WHEN** 实例完成登记
- **THEN** 系统通过注册中心的查询接口能把该实例查回来
- **AND** 启动日志中出现明确的「注册已校验」记录

#### Scenario: 注册未生效

- **WHEN** 登记调用返回成功但查询不到该实例
- **THEN** 系统输出明确告警，说明「登记未生效」而不谎报成功

### Requirement: 服务清单登记

每个对外提供工具或能力的服务 SHALL 把自身的服务标识、协议类型、访问端点、版本登记到注册中心。
工具的参数结构（schema）真值 MUST 保留在原服务，注册中心 MUST NOT 成为 schema 的第二处真值。

#### Scenario: 登记 MCP 服务清单

- **WHEN** 一个 MCP 服务启动并开启登记
- **THEN** 注册中心上能查到该服务的标识、协议类型、访问端点与版本
- **AND** 该记录中不包含工具参数的完整结构定义，只包含工具名与摘要

#### Scenario: 服务清单随版本变化

- **WHEN** 该服务以新的版本号重新启动
- **THEN** 注册中心上的版本信息更新为新版本，旧版本记录不再对应健康实例

### Requirement: 注册中心不可用时的显式降级

注册中心 SHALL 不承载业务语义。它不可用时，服务 MUST 仍能启动并按本地配置完成能力发现，
同时 MUST 输出明确告警，MUST NOT 静默退回。

#### Scenario: 调用方启动时注册中心不可达

- **WHEN** 调用方启动时注册中心不可达
- **THEN** 调用方按本地配置的实例清单继续工作
- **AND** 启动日志中出现包含注册中心地址与失败原因的告警

#### Scenario: 运行中注册中心不可达

- **WHEN** 运行期查询注册中心失败
- **THEN** 该次查询退回本地配置的实例清单
- **AND** 已经建立的业务对话不因此中断

#### Scenario: 注册中心恢复

- **WHEN** 注册中心从不可用恢复为可用
- **THEN** 后续查询重新以注册中心的结果为准，无需重启调用方

### Requirement: 健康实例优先

调用方 SHALL 只把健康实例纳入可调用集合，MUST NOT 把已下线或不健康的实例分发给业务请求。

#### Scenario: 存在不健康实例

- **WHEN** 注册中心上某个实例被标记为不健康
- **THEN** 该实例不出现在调用方的可调用集合中

#### Scenario: 实例全部不健康

- **WHEN** 注册中心上该服务的全部实例都不健康
- **THEN** 调用方退回本地配置的实例清单并输出告警
